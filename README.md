# lg-st-apps-data

Public pages and open data for my LG webOS TV apps, published with GitHub Pages at
<https://abedshouman.github.io/lg-st-apps-data/>.

Each app has its own folder:

| Folder | App | Contents |
|---|---|---|
| [`go-to-pray/`](go-to-pray) | Go To Pray (`com.abed.gotopray`) | Credits, privacy policy (EN/FR/AR), countries/states/cities data (ODbL 1.0, see [its licence](go-to-pray/LICENSE.md)) |

Licences differ per folder; see each folder's `LICENSE.md`.
